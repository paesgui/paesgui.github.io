Projetos

Pipeline de Dados CNPJ

Pipeline de ingestão e transformação de dados públicos da Receita Federal para construir uma base organizada para análises sobre empresas brasileiras.

Problema
Transformar arquivos públicos extensos em dados estruturados, organizados e preparados para análise.
Solução
Ingestão e processamento com Python, armazenamento no S3, carga no Snowflake e transformação com dbt nas camadas Bronze, Staging e Marts.
Dados
Cadastro Nacional da Pessoa Jurídica (CNPJ) — Receita Federal do Brasil.
Ferramentas
Python, AWS S3, Snowflake, SQL, dbt e Git/GitHub
Resultado
10 modelos analíticos e 16 testes de qualidade aprovados na última execução registrada do dbt build.

Bank Fraud Analytics

Pipeline de dados para análise de fraudes bancárias, desde a ingestão de transações até a disponibilização de indicadores em um dashboard interativo.

Problema
Entender onde e como as fraudes se concentram.
Solução
Pipeline da ingestão das transações até um dashboard interativo.
Dados
Dataset de transações bancárias do Kaggle
Ferramentas
Google Cloud Storage, BigQuery, SQL, Docker e Metabase
Resultado
Base analítica estruturada para investigar padrões e concentrações de fraude por método de pagamento, dispositivo e localização.
